# Bluetooth jammer 
DISCLAIMER: This project is for educational and security research purposes only. The user is solely responsible for compliance with local laws regarding radio interference


This is a small 44 x 60 mm 2.4ghz wifi and Bluetooth jammer/deauther. It uses an ESP32 and two nRF24L01+PA+LNA! It's based on a video I came across on YouTube where someone made a similar project.
